# 社内アプリ リンク集（SCTV LINK HUB）

社内向けアプリへのリンクをまとめたスマホ向けリンク集です。リンクの中身は **Google スプレッドシート**で管理し、管理ページ（またはスプレッドシートを直接編集）で更新すると、パスワードを知っている全員のスマホ・PCに反映されます。サイト自体は GitHub Pages でそのまま公開できる静的サイト（HTML/CSS/JavaScriptのみ、ビルド不要）です。

## 構成

```
index.html                リンク集トップページ（パスワード認証つき）
admin.html                リンクの追加・編集・削除を行う管理ページ（毎回パスワード認証）
assets/style.css          デザイン（白背景・濃紺メイン・オレンジ差し色）
assets/config.js          Google スプレッドシート連携用の設定（API URLをここに書く）
assets/sheet-api.js       Google Apps Script(スプレッドシート) と通信する共通処理
assets/storage.js         「この端末はログイン済み」を記憶するlocalStorage処理
assets/app.js             トップページのロジック
assets/admin.js           管理ページのロジック
google-apps-script/Code.gs  スプレッドシート側に貼り付ける Apps Script（バックエンド）
```

## 全体のしくみ

```
[Google スプレッドシート] --- リンク一覧を保存 ---
        │
        │ (Apps Script を「ウェブアプリ」として公開)
        ▼
[Apps Script Web App] --- パスワードが正しい時だけ JSON を返す/更新する ---
        │
        │ JSONP (<script>タグ経由。fetch()だとCORSで弾かれるため)
        ▼
[index.html / admin.html]  ← みんなのスマホ・PC (GitHub Pages で公開)
```

- リンクの中身（URL・名称・説明）はサイトのファイルには一切含まれていません。ページを開くたびに、入力されたパスワードを添えて Apps Script にリクエストし、正しい場合だけスプレッドシートの中身を取得して表示します。
- そのため、**ログイン前に開発者ツールでソースを見ても中身は一切表示されません**（データそのものがまだサーバー側にあり、届いていないため）。
- 通信方式には `fetch()` ではなく **JSONP**（`<script>`タグでデータを読み込む方式）を使っています。Google Apps Script のウェブアプリは `fetch()`（CORS）からだと正常に読み取れないことがあるための対策です。
- 管理ページで保存すると Apps Script 経由でスプレッドシートが書き換わり、以降 誰かがトップページを開くたびに最新の内容が取得されます＝**全員のスマホに反映**されます。
- 管理者は、管理ページを使わずに **Google スプレッドシートを直接編集**しても構いません（同じデータを見ているため、次にトップページ/管理ページを開いたときに反映されます）。

## パスワード

現在のパスワードは **`2121`** です（Apps Script 側のスクリプトプロパティ `SITE_PASSWORD` で管理。変更方法は下記）。

## 主な仕様

- **パスワード認証**：トップページ・管理ページともに `2121` の入力が必須です。
- **端末の記憶**：トップページは一度ログインに成功した端末では、次回以降パスワード入力なしで自動的に表示されます（`localStorage` にパスワードを記憶し、次回訪問時に自動でスプレッドシートへ問い合わせます）。「この端末のログイン情報を削除する」リンクでいつでも解除できます。
- **管理ページは毎回認証**：トップページでログイン済みの端末でも、管理ページ (`admin.html`) に入る際は必ずパスワード入力が必要です。
- **デザイン**：白背景／文字とメインカラーは濃紺／差し色はオレンジ。スマホでの利用を想定し、リンクボタンは大きめのタップ領域にしています。

## セットアップ手順（初回のみ・Googleアカウントでの作業）

### 1. スプレッドシートを作成する

Google スプレッドシートを新規作成し、シート(タブ)名を `links` にして、1行目に見出し、2行目以降にリンクを入力します。

| id | name | url | description |
|---|---|---|---|
| campaign | ①キャンペーン確認サイト | https://tvss2p.github.io/sctv-campaign-site/ | キャンペーン内容・重畳適用可否などを確認できます。 |
| koujihi | ②工事費判定ツール | https://tvss2p.github.io/SCTV-koujihi/ | 各種工事費を確認できます。 |
| duty | ③酒気帯びチェック・警備 | http://192.168.0.250/duty/ | 社内ネットワークからのみアクセス可能。 |
| equipment | ④備品購入リクエスト | https://tvss2p.github.io/equipment/ | 備品買い出しのリクエスト受付。 |
| marketing | ⑤Ｅラーニング「マーケティングのいろは」 | https://tvss2p.github.io/sctv-marketing-school/ | マーケティングの考え方について学べるＥラーニング。 |

（`id` は空欄でも動作しますが、行の識別用に一意な文字列を入れておくことをおすすめします）

### 2. Apps Script を貼り付ける

1. スプレッドシートのメニューから「拡張機能」→「Apps Script」を開きます。
2. デフォルトで開かれる `コード.gs`（または `Code.gs`）の中身を、このリポジトリの [`google-apps-script/Code.gs`](google-apps-script/Code.gs) の内容にすべて置き換えます。
3. 左メニューの「プロジェクトの設定」（歯車アイコン）→「スクリプト プロパティ」で、プロパティを追加します。
   - プロパティ名: `SITE_PASSWORD`
   - 値: `2121`
   （設定しなくてもコード内の既定値 `2121` が使われますが、パスワードを変更したいときはここだけ書き換えれば済みます）

### 3. ウェブアプリとしてデプロイする

1. Apps Script エディタ右上の「デプロイ」→「新しいデプロイ」を選択。
2. 種類の選択（歯車アイコン）で「ウェブアプリ」を選ぶ。
3. 設定：
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 「デプロイ」をクリックすると、Google アカウントへのアクセス許可を求められるので許可します（このスクリプトがスプレッドシートを読み書きするための許可です）。
5. デプロイ完了後に表示される **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec` の形式）をコピーします。

> **重要**：`Code.gs` のコードを更新した場合は、それだけではURLの中身は更新されません。必ず「デプロイ」→「デプロイを管理」→ 該当のデプロイの鉛筆アイコン →「バージョン: 新バージョン」を選んで「デプロイ」を押してください（URLは変わりません）。これを忘れると、コードを直しても古い動作のままになります。

### 4. サイト側にURLを設定する

`assets/config.js` を開き、`SHEET_API_URL` に手順3でコピーしたURLを設定します。

```js
window.SCTV_CONFIG = {
  SHEET_API_URL: "https://script.google.com/macros/s/xxxxxxxxxxxxxxxxxxxx/exec",
};
```

保存して GitHub Pages に反映（コミット & プッシュ）すれば設定完了です。

## 使い方（運用開始後）

- **リンクを見る人**：トップページを開いてパスワード `2121` を入力するだけです。
- **リンクを編集する人（管理者）**：以下のどちらでもOKです。
  - 管理ページ (`admin.html`) を開いてパスワードを入力し、フォームで編集して「保存する」を押す。
  - Google スプレッドシートを直接開いて、行を追加・編集・削除する。

どちらの方法で更新しても、次にだれかがトップページ／管理ページを開いたときに最新の内容が表示されます。

## セキュリティに関する注意

- パスワードは4桁の数字のみです。Apps Script 側でパスワード確認をしているため、正しいパスワードを知らない限りリンクの中身（URLや社内ツールの情報）を取得することはできませんが、桁数が短いため総当たりに対する強度は高くありません。より高いセキュリティが必要な場合は、パスワードを長く複雑なものに変更する、または Google アカウントでのログイン制限（アクセスできるユーザーを「自分のドメインのユーザーのみ」に変更するなど）をご検討ください。
- Apps Script の「アクセスできるユーザー：全員」は、URLとパスワードの組み合わせを知っている人だけがデータを取得できる設定です。ウェブアプリのURL自体は公開範囲を制限できないため、リンクの一覧に本当に機密性の高い情報（パスワードや個人情報など）を含めないようにしてください。

## デプロイ方法（GitHub Pages）

1. このリポジトリの Settings → Pages で、公開ブランチを `main`（または運用しているブランチ）、公開ディレクトリを `/`（ルート）に設定します。
2. 数分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。
3. 上記セットアップ手順で取得した Apps Script の URL を `assets/config.js` に設定してからアクセスしてください。
